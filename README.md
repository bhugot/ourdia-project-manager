# Ourdia Project Manager

Suivi des issues et des sessions de `bhugot/ourdia` depuis le téléphone : une page statique, sans serveur ni code tiers, qui lit l'API GitHub avec un jeton personnel.

Voir `CLAUDE.md` pour les règles et `docs/superpowers/specs/` pour la conception.

Tests : `npm test` (Node 22 ou plus, aucune dépendance).
